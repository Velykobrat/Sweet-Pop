# Sweet Pop

Responsive promotional landing page for the **Sweet Pop** mobile game.

The project was developed as a team project and delivered in 2024.  
The original version is preserved in the
[`v1.0-original`](../../releases/tag/v1.0-original) tag.

A portfolio refresh is currently in progress to improve accessibility, SEO, code
quality and overall presentation while preserving the original project history.

## Live Demo

https://velykobrat.github.io/Sweet-Pop/

## About the Project

Sweet Pop is a promotional website for a mobile puzzle game.

The landing page introduces the game, presents its main features and gameplay,
showcases screenshots and directs users to Google Play.

The website includes:

- responsive navigation
- game presentation and screenshots
- interactive gallery
- How to Play section
- Benefits section
- FAQ
- Google Play integration
- Privacy Policy and Terms & Conditions pages
