# Sweet Pop

Responsive promotional website for **Sweet Pop**, a colorful candy-matching
mobile puzzle game.

The project was developed as a **team frontend project** based on a provided
design. The main goal was to accurately reproduce the design, build responsive
layouts, and implement interactive elements using Vanilla JavaScript and SCSS.

## Live Demo

https://velykobrat.github.io/Sweet-Pop/

## About the Project

Sweet Pop is a promotional website for a mobile puzzle game.

The website introduces the game, presents gameplay screenshots and key features,
explains how to play, and provides a direct link to the game on Google Play.

Special attention was given to:

- accurate implementation of the provided design;
- responsive behavior across screen sizes;
- reusable SCSS structure;
- interactive gallery navigation;
- mobile navigation;
- lightweight animations;
- image optimization;
- accessibility improvements.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Velykobrat/Sweet-Pop.git
cd Sweet-Pop
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
